# Senior_Design_Project

Modern baseball analytics rely heavily on complex biomechanical and athletic-performance metrics, often favoring players with exceptional physical traits. This project investigates whether a simplified feature pool centered on plate discipline, swing decisions, and hitting approach—essentially “baseball IQ”—can meaningfully predict offensive output. Using Statcast data from 2015–2025, engineered features derived from PCA, and multiple machine learning models (linear regression, ridge regression, random forests, and a neural network), the project evaluates the predictive power of decision-making variables for estimating weighted runs above average (wRAA). Results show that hitting approach and batted-ball direction outperform swing decision metrics in predictive significance, suggesting that offensive evaluation may benefit from emphasizing approach-based features rather than plate discipline alone.
